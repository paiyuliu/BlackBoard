# BlackBoard 數位黑板

一個簡單好用的數位黑板應用程式，可直接在瀏覽器中使用，無需安裝。

🔗 **[立即使用 → https://paiyuliu.github.io/BlackBoard/](https://paiyuliu.github.io/BlackBoard/)**

---

## 功能特色

- 🖊️ **多色粉筆** — 白色、紅色、黃色，模擬真實粉筆質感
- 📏 **粗細調整** — 支援滑桿拖曳、數字輸入框直接輸入，以及 ▲ / ▼ 按鈕微調筆觸粗細
- 🧽 **板擦工具** — 擦除任意區域
- 📝 **文字工具** — 點擊黑板任意位置輸入文字，可調整字體、大小與粗體
- ↶ **恢復上一動** — 支援多步驟 Undo
- 🗑️ **清空黑板** — 一鍵清除所有內容
- 💾 **匯出 PNG** — 將黑板內容存成圖檔
- 📱 **觸控支援** — 支援手機與平板觸控操作
- 🙈 **工具欄切換** — 可隱藏工具欄以最大化繪畫空間

## 使用方式

直接開啟 [https://paiyuliu.github.io/BlackBoard/](https://paiyuliu.github.io/BlackBoard/) 即可使用，無需安裝任何套件。

若要在本地端執行，只需將本專案下載後用瀏覽器開啟 `index.html` 即可。
